1. First time — calculate and save the SHA-256

Assuming the DVD drive is /dev/sr0:

sudo dd if=/dev/sr0 bs=4M status=progress | sha256sum | tee dvd-sha256.txt


You'll get something like:
a1b2c3d4...  -

The hash is saved in dvd-sha256.txt.



2. Later — calculate it again
Insert the same DVD-R and run:


sudo dd if=/dev/sr0 bs=4M status=progress | sha256sum




Compare the result with the value you saved.
If they are exactly the same, the data read from the DVD is identical.
